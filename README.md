# 🦠 COVID-19 Data Analysis Project

## 📌 Project Overview
This project analyzes global COVID-19 data to understand trends in **cases, deaths, and vaccinations** across countries and over time.  
The analysis focuses on exploring key metrics, comparing regions, and deriving insights using SQL-based data analysis techniques.

---

## 📊 Dataset
- **Source:** Our World in Data  
- **Link:** https://ourworldindata.org/covid-deaths  

The dataset includes worldwide COVID-19 information such as:
- Daily and cumulative cases and deaths
- Population data
- Vaccination statistics
- Country and continent-level breakdowns
- Time-series records by date

---

## 🎯 Objectives
- Explore global COVID-19 trends over time
- Compare infection and death rates across countries and continents
- Analyze COVID-19 deaths relative to population size
- Examine vaccination progress and coverage
- Practice SQL data cleaning, aggregation, and analytical queries

---

## 🛠️ Tools & Technologies
- SQL (Microsoft SQL Server)
- SQL Server Management Studio (SSMS)
- CSV datasets (COVID deaths & vaccinations)

---

## 🧹 Data Preparation & Cleaning
Key preprocessing steps include:
- Importing COVID-19 deaths and vaccination datasets into SQL Server
- Filtering out aggregated rows (e.g., world-level totals)
- Handling missing and null values
- Ensuring correct data types for dates and numeric columns
- Joining deaths and vaccination tables for combined analysis

---

## 📈 Analysis Highlights
- Calculated death rates by country and continent
- Compared total cases and deaths relative to population size
- Analyzed vaccination rollout progress over time
- Identified countries with the highest infection and mortality rates
- Used SQL aggregations, window functions, and joins for insights
